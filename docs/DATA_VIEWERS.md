# 📊 데이터 및 문서 뷰어 스튜디오 아키텍처 (Data Viewers Studio Architecture)

Util-Tools는 대용량 테이블, 기술 문서, 다이어그램을 별도의 무거운 서드파티 프로그램 없이 조회, 편집, 변환할 수 있는 3대 통합 뷰어 스튜디오를 내장하고 있습니다:
1. **📋 CSV / TSV 뷰어 및 다중 포맷 변환기**
2. **📝 Markdown 실시간 인터랙티브 스튜디오 (GFM / Alerts / Mermaid)**
3. **📊 Mermaid 다이어그램 비주얼 스튜디오**

---

## 1. 📋 CSV / TSV 뷰어 및 데이터 변환기

### 1-1. 핵심 기능 및 아키텍처
- **인코딩 자동 판별**: 한글 깨짐의 주요 원인인 `CP949 / EUC-KR`과 `UTF-8 / UTF-8 with BOM`을 바이트 단위로 자동 판별하여 깨짐 없이 즉시 오픈.
- **구분자(Delimiter) 자동 감지**: 쉼표(`,`), 탭(`\t`), 세미콜론(`;`), 파이프(`|`)를 첫 줄 스캔으로 자동 인식.
- **클립보드 표 붙여넣기**: 엑셀이나 웹에서 복사한 셀 데이터를 단축키(`Ctrl+V`)로 즉시 테이블 형태로 렌더링.
- **가상 스크롤 및 고속 정렬/검색**: 테이블 실시간 필터링 및 컬럼별 오름차순/내림차순 정렬 지원.

### 1-2. 4대 다중 포맷 데이터 변환기
| 변환 포맷 | 출력 사양 및 특징 |
| :--- | :--- |
| **Markdown 표** | GitHub Flavored Markdown 규격의 `\| Header \|` 텍스트로 즉시 변환 및 복사 |
| **JSON 배열** | 컬럼명을 키(Key)로 사용하는 표준 JSON 객체 배열(`[{"col": "val"}]`) 변환 |
| **SQL INSERT 문** | 대상 테이블명을 지정하여 즉시 DB에 주입 가능한 `INSERT INTO table (...) VALUES (...)` 일괄 생성 |
| **필터된 CSV** | 검색 및 정렬된 결과만을 반영한 새로운 정제 CSV 파일 다운로드 |

## 2. 📝 Markdown 인터랙티브 스튜디오 (Markdown Studio)

### 2-1. GFM 및 확장 문법 지원
- **GitHub Alert 콜아웃 시각화**:
  - `[!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]`, `[!CAUTION]` 5종의 깃허브 표준 콜아웃 박스를 전용 다크 테마 디자인과 아이콘으로 렌더링.
- **인터랙티브 태스크 체크박스 동기화 (양방향 소스 바인딩)**:
  - 미리보기(Preview) 화면에서 체크박스(`- [ ]` / `- [x]`)를 마우스로 클릭하면, 에디터 본문의 원본 마크다운 소스가 실시간으로 자동 갱신되어 저장됩니다.
- **인라인 Mermaid 다이어그램 자동 렌더링**:
  - ```` ```mermaid ```` 코드 블록 작성 시 실시간으로 파싱하여 벡터 SVG 그래픽으로 즉시 렌더링.

### 2-2. 편의 기능
- **3대 뷰 모드**: Split(분할), Editor Only, Preview Only 모드 전환.
- **동기화 스크롤 (Sync Scroll)**: 에디터 스크롤 시 미리보기 화면이 같은 비율로 부드럽게 추종.
- **자동 목차(TOC) 생성**: 문서 내 `#`, `##`, `###` 헤더를 분석하여 클릭 시 해당 섹션으로 즉시 스크롤되는 목차 자동 삽입.

## 3. 📊 Mermaid 다이어그램 비주얼 스튜디오

### 3-1. 16종 다이어그램 프리셋 템플릿 내장
Flowchart, Sequence, Class, State, ERD, User Journey, Gantt, Pie Chart, Requirement, GitGraph, Mindmap, Timeline, Quadrant, C4, Architecture, Sankey 등 16종의 표준 템플릿 제공.

### 3-2. 인터랙티브 조작 및 고해상도 내보내기
- **줌 & 팬 컨트롤**: 마우스 휠 줌(Zoom) 및 드래그 패닝(Pan) 지원.
- **고해상도 내보내기**:
  - **SVG 벡터 다운로드**: 웹 및 문서 삽입용 무손실 벡터 파일.
  - **PNG 고화질 다운로드 & 클립보드 복사**: 2배수 렌더링으로 선명한 래스터 이미지 생성.
- **중앙 SQLite 영구 보관**: 작성한 다이어그램은 `diagrams` 테이블에 자동 저장되어 카테고리별로 관리됩니다.
