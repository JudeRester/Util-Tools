# 📧 이메일 아카이브 시스템 및 스레드 아키텍처 (Email Archive Architecture)

Util-Tools는 수천 통의 `.eml` 및 `.msg` 이메일을 로컬에서 안전하게 보관하고, 대화 스레드 분석 및 AI 시맨틱 검색을 제공하는 이메일 관리 엔진을 내장하고 있습니다.

## 2. 💬 대화별 스레드 묶기 (Thread View) & 타임라인 라이프사이클

이메일 제목에서 `Re:`, `Fwd:`, `[회수]`, `답장:`, `전달:` 등 모든 불필요한 접두사를 제거하여 고유의 `thread_key`로 대화를 그룹화합니다.  
`[💬 대화 묶기]` 토글을 활성화하면 3,100여 건의 개별 메일이 약 1,000개의 대화 스레드로 압축되어 메일함 피로도를 대폭 낮춥니다.

```mermaid
sequenceDiagram
    autonumber
    actor User as 사용자
    participant List as 이메일 목록 (Thread View)
    participant Timeline as 대화 타임라인 뷰 (Accordion)
    
    User->>List: "💬 대화 묶기" 활성화 (3,100건 -> 1,000 스레드)
    User->>List: [💬 4건] "서버 점검 및 배포 일정" 클릭
    List->>Timeline: 타임라인 아코디언 렌더링 요청
    Timeline-->>User: [1] 최초 요청 메일 (접힘 상태)
    Timeline-->>User: [2] 1차 회신 메일 (접힘 상태)
    Timeline-->>User: [3] 일정 조율 회신 (접힘 상태)
    Timeline-->>User: [4] 최종 확정 메일 (펼쳐짐 + 첨부파일 목록)
```

## 3. 📥 IMAP 단방향 누적 아카이빙 & 보안 가드 (`services/imap_service.py`)

### 3-1. 무의존성 IMAP4_SSL 단방향 동기화 아키텍처
- **단방향 누적 영구 보관**: Python 표준 라이브러리 `imaplib` + `ssl`로 메일 서버에서 신규 메일(Message-ID / UID 중복 제거)의 RFC 822 원본을 내려받아 `emails/*.eml`과 SQLite `emails` 테이블에 영구 저장합니다. 이후 메일 서버에서 메일이 삭제되거나 변경되어도 로컬 아카이브에는 영향을 주지 않습니다.
- **이중 인증 모드 지원 (`imap_accounts` 테이블)**:
  - **일반 / 앱 비밀번호 (`password`)**: Google 16자리 앱 비밀번호 복사 시 포함되는 공백을 자동 정규화(`_normalize_imap_credentials`)하고, Gmail/Naver/Daum 도메인 자동 보정 및 한국어 오류 가이드를 제공합니다.
  - **Google OAuth 2.0 (`oauth2_google` / `XOAUTH2`)**: 로컬 루프백 HTTP 서버를 통한 브라우저 인증, `userinfo` 기반 이메일 주소 보정, `https://mail.google.com/` 스코프 누락 사전 검증, 액세스 토큰 자동 갱신, 그리고 토큰 만료(`invalid_grant`) 시 30초 무한 재시도를 차단하고 재로그인 알림을 표시합니다.
- **백그라운드 주기 폴링 & 자동 AI 벡터 임베딩**:
  - 계정별 `poll_interval_minutes` 설정에 따라 백그라운드 데몬이 주기적으로 신규 메일을 수집하며, 툴바 `[📥 IMAP 동기화]` 버튼으로 수동 동기화도 실행할 수 있습니다.
  - 신규 메일 저장 직후 로컬 `Multilingual-E5` ONNX 임베딩 파이프라인을 호출하여 `ai_embeddings` 벡터 캐시를 자동 갱신합니다.
- **RFC 3501 Modified UTF-7 사서함 호환**: `[Gmail]/&vPSwuNO4ycDVaA-`와 같은 한글 사서함 폴더명을 디코딩하여 선택할 수 있습니다.

### 3-2. HTML 외부 이미지(트래킹 픽셀) 및 원격 리소스 기본 차단 가드 (`web/js/email_viewer.js`)
- HTML 본문 렌더링 시 외부 URL 이미지(`http://`, `https://`), 원격 스타일시트, 트래킹 픽셀(1×1 px 비콘)을 **기본 차단**하여 수신 확인 추적 및 의도치 않은 외부 네트워크 요청을 방지합니다.
- 외부 리소스가 차단된 메일 상단에 안내 배너를 표시하며, 사용자가 신뢰하는 발신자의 메일에서만 수동으로 외부 이미지 로드를 허용할 수 있습니다.

## 4. 🌟 이메일 핵심 기능 특징

1. **💬 비파괴적 대화별 스레드 묶기 (Thread View)**:
   * 동일한 주제로 오고 간 메일들을 시간순(과거 ➔ 최신) 아코디언 카드 뷰로 렌더링.
   * 각 카드별 HTML/Text 뷰 모드 전환, 개별 본문 복사, 원본 열기 지원.
2. **⚡ 청크 페이징 & 지연 로딩 (Lazy Loading)**:
   * 140MB+ 대용량 이메일도 50~300개 단위의 경량 메타데이터 청크로 로드하여 브라우저 메모리를 40MB 수준으로 유지.
   * 사용자가 클릭한 메일만 SQLite에서 온디맨드로 상세 본문 조회.
3. **🧠 로컬 딥러닝 AI 시맨틱 문맥 검색 (`Ctrl+K`)**:
   * "서버 응답 지연", "비용 견적 요청" 등 자연어로 질문 시 AI가 의미적 유사도를 판단하여 관련 메일을 검색.
   * 검색 결과 클릭 시 해당 메일이 속한 대화 스레드로 자동 스크롤 및 선택.
4. **🏷️ 6대 카테고리 자동 분류 및 통계 칩**:
   * 업무/프로젝트, 회의록, 견적/계약, 인사/총무, 시스템/알림, 기타 카테고리 자동 분류 및 실시간 건수 통계.
5. **📎 첨부파일 온디맨드 추출 & 일괄 저장**:
   * 메일 내 첨부파일(PDF, 엑셀, 이미지 등)을 온디맨드로 임시 추출하여 OS 기본 프로그램으로 실행.
   * `[📦 전체 첨부파일 일괄 저장]`을 통해 원하는 디렉토리에 일괄 다운로드.
6. **📥 대량 EML 드래그 앤 드롭 & IMAP 누적 아카이빙**:
   * 탐색기에서 `.eml` 파일들을 브라우저 위로 드래그 앤 드롭하거나 IMAP 계정을 연동하여 SQLite와 `emails/` 폴더에 영구 보관.

## 5. 📦 이메일 백업(Export) 및 원본 파일 저장 구조

| 구분 | **통합 백업 JSON / ZIP (Export 시)** | **로컬 하드디스크 (`emails/` 폴더)** |
| :--- | :--- | :--- |
| **저장 형태** | 단일 `.json` 또는 90% 압축 `.zip` 백업 파일 내 `data.emails` 배열 | 실제 원본 파일 (`emails/*.eml`) |
| **포함 내용** | 발신/수신자, 정규화 제목, 날짜, 카테고리, **전체 텍스트/HTML 본문**, 스레드 키, 첨부파일 메타데이터 | 이메일 원본 전체 (바이너리 MIME 스트림 포함) |
| **주요 용도** | **타 PC 마이그레이션 / 스키마 독립 백업 & 복원** | Outlook 등 **OS 기본 메일 프로그램으로 원본 열기** |
